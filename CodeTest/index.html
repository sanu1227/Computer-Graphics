휴대폰·미리보기용 스크립트 없는 열람판

검색 기능을 시작하지 못했다면 이 미리보기에서 스크립트가 제한될 수 있습니다. 위의 열람판을 사용하세요. 인터넷은 필요하지 않습니다.

복붙 순서와 조합 규칙
  1. 가장 가까운 기능을 선택하고 전체 실행 코드를 새 .cpp 하나에 복사한다.
  2. 다른 기능은 기능 블록의 namespace 전체를 FEATURE_BLOCK_END 앞에 붙인다.
  3. 호출 등록부의 호출문을 기존 OnReset / OnKey / OnUpdate / OnDraw 등에 합친다. 함수 정의 자체를 중복해서 붙이지 않는다.
  4. 카메라처럼 보조 기능만 필요하면 그 기능의 Draw 호출을 제외한다. 조합 예제 23·24 참고.
  5. 2D와 3D의 Reset을 무작정 섞지 않는다. 같은 화면의 좌표계와 카메라 설정은 하나로 결정한다.

F5 초기화 · Esc 종료. x64, C++17 이상. 링크: opengl32.lib glew32.lib glfw3.lib. 기존 실습과 키는 다를 수 있으므로 각 항목의 키를 확인한다.
