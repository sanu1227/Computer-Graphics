# 1-19 탱크와 카메라

[1-19.cpp](../1-4/1-4/1-19.cpp)는 「지엘3 좌표계 변환 (실습 1819)」 PDF 3~4쪽을 구현한다. 육면체 9개로 탱크를 만들고 원근 투영과 은면 제거를 적용한다.

## 실행

프로젝트의 `1-4/1-4` 폴더에서 실행한다.

```powershell
.\run-exercise.ps1 -Number 19
```

Visual Studio 기본 과제는 18번이다. IDE에서 19번을 실행하려면 `1-4.vcxproj`의 `Exercise` 기본값을 `18`에서 `19`로 바꾼다. 스크립트로 선택하면 프로젝트 기본값은 유지된다.

| 키 | 동작 |
| --- | --- |
| `←` / `→` | 탱크 x좌표 감소 / 증가 |
| `↑` / `↓` | 탱크 z좌표 감소 / 증가 |
| `d` | 아래 몸체 높이 변화 시작 / 정지 |
| `t` | 중앙 몸체 y축 회전 시작 / 정지 |
| `l` | 상부 몸체 둘이 2초 동안 이동하여 자리 교환 |
| `g` | 양쪽 포신의 반대 방향 y축 회전 시작 / 정지 |
| `p` | 양쪽 깃대의 반대 방향 x축 회전 시작 / 정지 |
| `z` / `Shift+z` | 카메라 z좌표 증가 / 감소 |
| `x` / `Shift+x` | 카메라 x좌표 증가 / 감소 |
| `y` / `Shift+y` | 카메라 자체 y축 기준 시계 / 반시계 자전 |
| `r` / `Shift+r` | 장면 중심 y축 기준 시계 / 반시계 공전 |
| `o` | 탱크 부품 색상 변경 |
| `c` | 탱크, 색상, 카메라, 애니메이션 초기화 |
| `q`, `Esc` | 종료 |

`y`, `r`은 같은 방향의 키를 다시 누르면 정지한다. 반대 방향의 키를 누르면 방향을 바꾼다. 시계방향은 해당 y축의 양의 방향에서 내려다본 기준이다. `l`은 교환 중에는 다시 시작하지 않으며, 끝난 뒤 다시 누르면 원래 자리로 돌아간다.

## 1. 프로그램 흐름

`KeyCallback()`이 입력을 받아 애니메이션 상태를 바꾼다. `UpdateAnimation()`이 시간을 진행한다. `GetPartTransforms()`가 각 부품의 변환을 만들고 `DrawScene()`이 바닥과 탱크를 그린다.

셰이더는 `1-19-vertex.glsl`, `1-19-fragment.glsl`을 사용한다. 기존 과제와 같은 GLFW/GLEW 초기화와 반복문 구조를 유지한다.

## 2. 육면체 하나로 부품을 만든다

`MakeVertices()`는 각 좌표가 -0.5~0.5인 육면체를 만든다. `MakeBox()`가 원하는 위치로 이동하고 가로·높이·깊이를 다르게 조절한다.

| 배열 번호 | 부품 |
| --- | --- |
| 0, 1 | 아래 몸체 2개 |
| 2 | 중앙 몸체 |
| 3, 4 | 상부 몸체 2개 |
| 5, 6 | 포신 2개 |
| 7, 8 | 깃대 2개 |

각 부품은 별도 색을 갖는다. `DrawBox()`는 면마다 밝기를 조금 다르게 주어 육면체의 면을 구분한다.

## 3. 부모 변환을 따라간다

탱크 전체 이동은 `tankPosition`이다. 중앙 몸체의 변환에는 전체 이동, 아래 몸체의 높이, 중앙 몸체의 y축 회전이 들어간다.

`GetUpperTransform()`은 중앙 몸체의 변환에 상부 위치를 더한다. 포신과 깃대는 다시 이 상부 변환을 사용한다. 따라서 중앙 몸체가 회전하면 상부 몸체, 포신, 깃대가 함께 움직인다. 아래 몸체는 중앙 몸체의 회전을 상속하지 않는다.

부모 행렬에는 부품 크기를 넣지 않는다. 크기는 각 부품을 그릴 때 마지막에 적용한다. 중앙 몸체를 넓게 만들었다고 포신까지 넓어지는 것을 막는다.

## 4. 바닥에서 뜨거나 벗어나지 않게 한다

아래 몸체의 높이는 0.4~0.8 사이에서 바뀐다. 아래 몸체의 중심을 `높이 / 2`에 두므로 밑면은 항상 y=0이다. 나머지 몸체는 이 높이 위에 쌓는다.

바닥은 x와 z가 -7~7인 정사각형이다. 탱크 중심은 -3.5~3.5로 제한한다. 포신과 깃대가 회전할 공간까지 남겨 모든 부품이 바닥 범위 안에 머문다.

## 5. 자리 교환과 부품 회전

상부 몸체는 서로 반대쪽 반원 경로로 움직여 자리를 바꾼다. 교환 중에도 색과 포신·깃대는 자기 몸체를 따라간다.

포신은 몸체 앞의 연결점으로 이동한 뒤 y축으로 회전한다. 마지막에 포신 중심을 길이의 절반만큼 앞으로 옮긴다. 따라서 포신이 연결점에서 떨어지지 않는다.

깃대도 몸체 위의 연결점을 먼저 잡고 x축으로 회전한다. 양쪽에 반대 부호를 곱해 서로 반대로 움직인다. 포신은 ±55도, 깃대는 ±40도 범위에서 왕복한다.

## 6. 카메라 자전과 공전

`cameraPosition`은 위치, `cameraRotation`은 자세다. `GetViewTransform()`은 카메라의 이동·회전 행렬을 역행렬로 바꾼다.

자전은 카메라 위치를 유지하고 자세만 바꾼다. 회전을 오른쪽에 곱하므로 카메라 자신의 y축을 사용한다.

공전은 장면 중심 y축으로 위치와 자세를 함께 돌린다. 초기 상태에서 시작하면 장면 중심을 바라보면서 주변을 돈다. x·z 이동은 월드 좌표 기준이며 카메라 자세는 유지한다.

최종 변환은 `원근 투영 * 카메라 역변환 * 부품 변환`이다. 창 크기가 바뀌면 원근 투영의 화면 비율도 바뀐다.
