# 작업 기록 양식

작업별로 docs/tasks/A-001.md 또는 docs/tasks/B-001.md 등에 복사한다. 한 작업의 담당자 한 명이 관리한다. 아래 빈 항목은 실제 사실로 채우며, 필요한 항목만 짧게 유지한다.

## 작업 시작

- 작업 ID / 제목:
- 담당자:
- 상태: 예정 / 진행 / 인계 가능 / 보류
- 작업 브랜치 / 시작 기준 커밋:
- 확인한 기획서·관련 작업:
- 목표:
- 수정할 파일·폴더:
- 완료 기준:
- 다른 작업과의 의존 관계:

## 진행·인계

- 변경 내용과 이유:
- 실제 수정 파일:
- 실행한 검증과 결과:
- 미검증 사항과 확인 방법:
- 공통 약속 변경 / 상대 담당에게 미치는 영향:
- 남은 문제 / 다음 작업:
- 로컬 커밋:
- 원격 푸시:
- main 통합:

## 중요한 AI 활용 사례가 있을 때

- 요청 요약:
- 사람의 검토·수정:
- 결과 확인:

기록을 공유하기 전까지 다른 PC에는 전달되지 않는다. 커밋·푸시·통합은 실제 수행한 상태를 각각 적는다. 요청하지 않은 Git 작업을 이 양식만 보고 실행하지 않는다.
