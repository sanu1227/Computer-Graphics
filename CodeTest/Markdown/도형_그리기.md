## D01 점

[복사할 코드](기능모음집.md#d01) · 2D · 검색: 정점 점 크기

**하는 일:** 화면의 한 위치를 점으로 표시합니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `glPointSize(size)` | `1 · size` | 점의 픽셀 크기. 12.0f면 12픽셀 크기를 요청합니다. 0보다 커야 하며 지원 크기 범위는 환경에 따라 다릅니다. |
| `Primitive(mode, vertices, model, color)` | `1 · mode` | 정점을 연결하는 방식. GL_POINTS=점, GL_LINES=두 점씩 선, GL_LINE_STRIP=연속선, GL_LINE_LOOP=닫힌 선, GL_TRIANGLES=세 점씩 삼각형, GL_TRIANGLE_FAN=첫 점 기준 부채꼴. |
|  | `2 · vertices` | {x,y,z} 정점들의 목록. 개수와 순서를 바꾸면 모양이 바뀝니다. 2D 예제의 z는 0이며 x/y는 논리 화면 좌표입니다. |
|  | `3 · model` | 정점에 적용할 위치·회전·크기 행렬 하나. glm::mat4(1)은 모델 변형 없음입니다. 카메라·투영은 base가 별도로 적용합니다. |
|  | `4 · color` | {r,g,b} 또는 Red/Blue 등의 색. 각 성분은 0~1, 예를 들어 {1,0,0}은 빨강입니다. |
| `glm::mat4(diagonal)` | `1 · diagonal` | 대각 성분 값. 1이면 대각만 1이고 나머지는 0인 단위행렬이 되어 모델 변형을 하지 않습니다. 모든 성분을 1로 채우는 의미가 아닙니다. |

**바꿀 값:** 400,300=위치, 12=점의 픽셀 크기, Yellow=색.

**주의:** 점 크기의 지원 범위는 그래픽 환경에 따라 다릅니다.

**함께 쓰기:** [D02 선·연결선·테두리](도형_그리기.md#d02)

## D02 선·연결선·테두리

[복사할 코드](기능모음집.md#d02) · 2D · 검색: 직선 선분 궤적 윤곽

**하는 일:** 두 점을 잇는 선분입니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `Primitive(mode, vertices, model, color)` | `1 · mode` | 정점을 연결하는 방식. GL_POINTS=점, GL_LINES=두 점씩 선, GL_LINE_STRIP=연속선, GL_LINE_LOOP=닫힌 선, GL_TRIANGLES=세 점씩 삼각형, GL_TRIANGLE_FAN=첫 점 기준 부채꼴. |
|  | `2 · vertices` | {x,y,z} 정점들의 목록. 개수와 순서를 바꾸면 모양이 바뀝니다. 2D 예제의 z는 0이며 x/y는 논리 화면 좌표입니다. |
|  | `3 · model` | 정점에 적용할 위치·회전·크기 행렬 하나. glm::mat4(1)은 모델 변형 없음입니다. 카메라·투영은 base가 별도로 적용합니다. |
|  | `4 · color` | {r,g,b} 또는 Red/Blue 등의 색. 각 성분은 0~1, 예를 들어 {1,0,0}은 빨강입니다. |

**바꿀 값:** 좌표 두 개를 바꿉니다. GL_LINE_STRIP은 여러 점을 순서대로 연결하고 GL_LINE_LOOP는 마지막과 처음도 연결합니다.

**주의:** GL_LINES는 두 정점씩 독립된 선을 만듭니다.

## D04 사각형

[복사할 코드](기능모음집.md#d04) · 2D · 검색: 직사각형 네모 크기 중심

**하는 일:** 중심 좌표와 전체 너비·높이를 받는 2D 사각형입니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `Rect(center, size, color, filled=true)` | `1 · center` | {x,y} 중심 좌표. 왼쪽 위 모서리 좌표가 아닙니다. 2D에서는 +x가 오른쪽, +y가 아래입니다. |
|  | `2 · size` | {width,height} 전체 너비·높이. {200,100}이면 중심에서 좌우 100, 위아래 50만큼 뻗습니다. |
|  | `3 · color` | {r,g,b} 색, 각 값 0~1. Yellow 같은 준비된 색 변수도 가능합니다. |
|  | `4 · filled` | true=면 채우기, false=테두리. 생략하면 true입니다. |

**바꿀 값:** 400,300=중심. 200,100=전체 너비·높이. 네 번째 인수 false를 추가하면 테두리입니다.

**주의:** 왼쪽 위 좌표가 아닌 중심 좌표입니다. 반너비를 전달하지 않습니다.

**함께 쓰기:** [C01 점이 사각형 안인지](충돌_스냅_점프.md#c01) · [I04 드래그](입력_선택_드래그.md#i04)

## D06 육면체·바닥

[복사할 코드](기능모음집.md#d06) · 3D · 검색: 상자 받침대 시소 판 크기

**하는 일:** 원점 중심 한 변 1인 상자를 늘리고 옮깁니다. 받침대·판·바닥을 같은 Box로 만듭니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |
| `S(size)` | `1 · size` | {x,y,z} 축별 크기 배율 하나. Box의 기본 한 변이 1이므로 {6,0.2,0.8}은 전체 길이·두께·폭이 됩니다. Sphere에서는 축별 반지름입니다. 0이면 해당 축이 납작해집니다. |

**바꿀 값:** S의 x,y,z=가로·높이·깊이. T의 y를 높이/2로 두면 아랫면이 y=0입니다. 바닥 예: T({0,-0.1f,0})*S({10,0.2f,10}).

**주의:** 한 번 호출하면 상자 하나입니다. 여러 개는 Box를 여러 번 호출합니다.

**함께 쓰기:** [T01 이동](변환_공전_관절.md#t01) · [T03 크기 변경](변환_공전_관절.md#t03) · [T04 여러 부품 함께 회전](변환_공전_관절.md#t04)

|  | `4 · color` | {r,g,b} 또는 Red/Blue 등의 색. 각 성분은 0~1, 예를 들어 {1,0,0}은 빨강입니다. |
| `glm::mat4(diagonal)` | `1 · diagonal` | 대각 성분 값. 1이면 대각만 1이고 나머지는 0인 단위행렬이 되어 모델 변형을 하지 않습니다. 모든 성분을 1로 채우는 의미가 아닙니다. |

**바꿀 값:** 좌표 네 개가 면의 모양입니다. 특정 면만 보이게 하려면 그 면의 호출을 if 조건으로 감쌉니다.

**주의:** 정점은 면의 둘레 순서로 지정합니다. 면 선택 상태는 I01의 bool 패턴을 씁니다.

## D10 격자 바닥

[복사할 코드](기능모음집.md#d10) · 3D · 검색: 격자무늬 격자무뉘 그리드 바닥 평면 칸 간격 GridFloor

**하는 일:** 원점 중심의 XZ 평면에 색이 있는 바닥과 격자선을 그립니다. 다른 모델과 무관하게 사용할 수 있습니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `GridFloor(halfCount=5, spacing=1, floorY=0, floorColor={0.35,0.35,0.35}, lineColor={0.7,0.7,0.7})` | `1 · halfCount` | 중심에서 한쪽 방향의 칸 수, 1 이상의 정수. 5이면 가로·세로 각각 10칸입니다. 늘리면 칸 수와 전체 크기가 함께 커집니다. 생략 시 5. |
|  | `2 · spacing` | 한 칸의 길이, 0보다 큰 장면 좌표 단위. 늘리면 칸 수는 같고 바닥이 커집니다. 전체 한 변은 2*halfCount*spacing입니다. 생략 시 1. |
|  | `3 · floorY` | 바닥 윗면의 Y 좌표. 0이면 발밑 높이 0인 물체가 닿는 바닥입니다. 음수도 가능하며 생략 시 0. |
|  | `4 · floorColor` | 바닥의 {r,g,b} 색, 각 값 0~1. 생략 시 {0.35,0.35,0.35}. 바닥 면의 명암은 Box에서 적용됩니다. |
|  | `5 · lineColor` | 격자선의 {r,g,b} 색, 각 값 0~1. 생략 시 {0.7,0.7,0.7}. 마지막 인자부터 생략할 수 있어 GridFloor()도 기본 설정으로 동작합니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |
| `S(size)` | `1 · size` | {x,y,z} 축별 크기 배율 하나. Box의 기본 한 변이 1이므로 {6,0.2,0.8}은 전체 길이·두께·폭이 됩니다. Sphere에서는 축별 반지름입니다. 0이면 해당 축이 납작해집니다. |
| `Primitive(mode, vertices, model, color)` | `1 · mode` | 정점을 연결하는 방식. GL_POINTS=점, GL_LINES=두 점씩 선, GL_LINE_STRIP=연속선, GL_LINE_LOOP=닫힌 선, GL_TRIANGLES=세 점씩 삼각형, GL_TRIANGLE_FAN=첫 점 기준 부채꼴. |
|  | `2 · vertices` | {x,y,z} 정점들의 목록. 개수와 순서를 바꾸면 모양이 바뀝니다. 2D 예제의 z는 0이며 x/y는 논리 화면 좌표입니다. |
|  | `3 · model` | 정점에 적용할 위치·회전·크기 행렬 하나. glm::mat4(1)은 모델 변형 없음입니다. 카메라·투영은 base가 별도로 적용합니다. |
|  | `4 · color` | {r,g,b} 또는 Red/Blue 등의 색. 각 성분은 0~1, 예를 들어 {1,0,0}은 빨강입니다. |
| `glm::mat4(diagonal)` | `1 · diagonal` | 대각 성분 값. 1이면 대각만 1이고 나머지는 0인 단위행렬이 되어 모델 변형을 하지 않습니다. 모든 성분을 1로 채우는 의미가 아닙니다. |

**바꿀 값:** halfCount=한쪽 칸 수, spacing=한 칸 길이, floorY=바닥 윗면 높이. 기본값은 10×10칸, 전체 크기 10×10입니다. 네 번째·다섯 번째 인자를 추가하면 바닥색·선색도 바뀝니다.

**주의:** 전역에 GridFloor 함수를 한 번 넣고 OnDraw에서 호출합니다. 같은 위치의 기존 Ground() 호출은 교체합니다. OnUpdate에는 그리기를 넣지 않습니다. 선은 바닥보다 0.01 높게 그립니다. halfCount<1 또는 spacing<=0이면 아무것도 그리지 않습니다.

## D11 체커 바닥

[복사할 코드](기능모음집.md#d11) · 3D · 검색: 체커보드 체커바닥 채커 체크무늬 격자무늬 두 색 번갈아 지그재그 바둑판 타일 CheckerFloor

**하는 일:** XZ 평면을 정사각형 타일로 채우고 두 색을 가로·세로로 번갈아 배치합니다. 모양을 빠르게 확인하려면 첫 인자를 3으로 바꾸어 3×3칸으로 그립니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `CheckerFloor(count=10, spacing=1, floorY=0, colorA={0.2,0.2,0.2}, colorB={0.8,0.8,0.8})` | `1 · count` | 한 변의 전체 칸 수, 1 이상의 정수. 3이면 3×3=9개 타일입니다. 홀수·짝수 모두 가능하며 생략 시 10. D10의 한쪽 칸 수 halfCount와 구분합니다. |
|  | `2 · spacing` | 한 칸의 길이, 0보다 큰 장면 좌표 단위. 전체 한 변은 count*spacing이며 원점을 중심으로 배치합니다. 생략 시 1. |

|  | `5 · colorB` | 두 번째 색 {r,g,b}, 각 값 0~1. x+z가 홀수인 칸을 채웁니다. 생략 시 연회색 {0.8,0.8,0.8}. 마지막 인자부터 생략할 수 있습니다. |
| `Primitive(mode, vertices, model, color)` | `1 · mode` | 정점을 연결하는 방식. GL_POINTS=점, GL_LINES=두 점씩 선, GL_LINE_STRIP=연속선, GL_LINE_LOOP=닫힌 선, GL_TRIANGLES=세 점씩 삼각형, GL_TRIANGLE_FAN=첫 점 기준 부채꼴. |
|  | `2 · vertices` | {x,y,z} 정점들의 목록. 개수와 순서를 바꾸면 모양이 바뀝니다. 2D 예제의 z는 0이며 x/y는 논리 화면 좌표입니다. |
|  | `3 · model` | 정점에 적용할 위치·회전·크기 행렬 하나. glm::mat4(1)은 모델 변형 없음입니다. 카메라·투영은 base가 별도로 적용합니다. |
|  | `4 · color` | {r,g,b} 또는 Red/Blue 등의 색. 각 성분은 0~1, 예를 들어 {1,0,0}은 빨강입니다. |
| `glm::mat4(diagonal)` | `1 · diagonal` | 대각 성분 값. 1이면 대각만 1이고 나머지는 0인 단위행렬이 되어 모델 변형을 하지 않습니다. 모든 성분을 1로 채우는 의미가 아닙니다. |

**바꿀 값:** count=한 변의 전체 칸 수, spacing=한 칸 길이, floorY=바닥 높이. 네 번째·다섯 번째 인자 colorA/colorB가 번갈아 채워집니다. (x+z)%2가 색을 결정하므로 다음 줄의 시작 색도 바뀝니다.

**주의:** 전역에 CheckerFloor 함수를 한 번 넣고 OnDraw에서 호출합니다. 타일은 두께 없는 면이며 기존 바닥과 같은 높이에 겹쳐 그리지 않습니다. D10 GridFloor는 선 격자용으로 별도 유지됩니다. D10의 halfCount와 달리 count=3이면 전체가 3×3칸입니다.
