## A01 일정 시간마다 실행

[복사할 코드](기능모음집.md#a01) · 3D · 검색: 타이머 주기 누적

**하는 일:** 1초마다 상태를 바꿉니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnUpdate 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `glm::mat4(diagonal)` | `1 · diagonal` | 대각 성분 값. 1이면 대각만 1이고 나머지는 0인 단위행렬이 되어 모델 변형을 하지 않습니다. 모든 성분을 1로 채우는 의미가 아닙니다. |

**바꿀 값:** 1.0=주기(초). while 안의 코드를 도형 생성·색 변경 등의 동작으로 바꿉니다.

**주의:** 주기는 0보다 커야 합니다. 0으로 초기화하는 대신 주기를 빼서 남은 시간을 보존합니다.

**함께 쓰기:** [I01 키 한 번·켜기 끄기](입력_선택_드래그.md#i01)

## A02 부드러운 왕복 각도

[복사할 코드](기능모음집.md#a02) · 3D · 검색: 시소 흔들기 팔 다리 사인 진동

**하는 일:** 각도를 -25도부터 +25도까지 부드럽게 왕복시킵니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnUpdate 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `std::sin(radians)` | `1 · radians` | 라디안 단위 각도. time*speed라면 time은 초, speed는 라디안/초입니다. 결과 범위는 -1~1입니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |
| `R(degrees, axis)` | `1 · degrees` | 회전각, 단위는 도. 15=15도, -15=반대 회전. 내부에서 라디안으로 변환하므로 직접 radians를 적용하지 않습니다. |
|  | `2 · axis` | {x,y,z} 회전축 벡터 하나. {1,0,0}=X, {0,1,0}=Y, {0,0,1}=Z. {0,0,0}은 사용하지 않습니다. |
| `S(size)` | `1 · size` | {x,y,z} 축별 크기 배율 하나. Box의 기본 한 변이 1이므로 {6,0.2,0.8}은 전체 길이·두께·폭이 됩니다. Sphere에서는 축별 반지름입니다. 0이면 해당 축이 납작해집니다. |

**바꿀 값:** 25=최대 기울기, 2=사인 함수의 각속도(라디안/초). 주기는 약 2π/2초입니다.

**주의:** 시소 손잡이까지 움직이려면 T04의 angle 대신 waveAngle을 사용합니다. 반대쪽 팔다리는 각도 앞에 -를 붙입니다.

**함께 쓰기:** [T04 여러 부품 함께 회전](변환_공전_관절.md#t04) · [T05 관절에 부품 붙이기](변환_공전_관절.md#t05)

## A03 정해진 시간 동안 보간

[복사할 코드](기능모음집.md#a03) · 3D · 검색: 목표 이동 자리 교환 progress mix

**하는 일:** 시작점에서 끝점까지 2초 동안 이동합니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnUpdate 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `std::min(a, b)` | `1 · a` | 비교할 첫 번째 값. |
|  | `2 · b` | 비교할 두 번째 값. 더 작은 값을 반환합니다. 예: min(1.0f,progress)는 진행률의 상한을 1로 제한하지만 하한은 제한하지 않습니다. |
| `glm::mix(start, end, u)` | `1 · start` | 시작 값. 위치·색 같은 벡터 또는 크기 같은 숫자입니다. |
|  | `2 · end` | 끝 값. start와 호환되는 형태·단위여야 합니다. |
|  | `3 · u` | 단위 없는 보간 비율. 0=시작, 1=끝, 0.5=중간. 함수 자체가 0~1로 제한하지 않으므로 진행률 범위는 별도로 관리합니다. |
| `glm::vec3(x, y, z) / glm::vec3(s) / glm::vec3(v4)` | `1 · x / 2 · y / 3 · z` | 세 숫자를 전달하면 각 성분으로 저장합니다. 위치/방향에서는 X/Y/Z, 색으로 쓰면 R/G/B입니다. |
|  | `1 · s (숫자 하나)` | 세 성분을 모두 같은 값으로 만듭니다. glm::vec3(0)은 {0,0,0}입니다. |
|  | `1 · v4 (vec4 하나)` | vec4의 x,y,z 성분만 가져오고 w는 제외합니다. 이 변환 자체가 w로 나누지는 않습니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |

**바꿀 값:** 2.0=소요 시간(양수), 두 vec3=시작과 끝. 자리 교환은 반대 방향 mix를 같은 progress로 계산합니다.

**주의:** 키로 시작할 때는 시작 위치를 그 순간 한 번 저장하고 progress를 0으로 만듭니다. 매 프레임 시작점을 현재 위치로 덮어쓰지 않습니다.

**함께 쓰기:** [A04 색·숫자 보간](시간_보간_애니메이션.md#a04) · [C02 사각형끼리 겹치는지](충돌_스냅_점프.md#c02)

## A07 정점 보간으로 모양 변경

[복사할 코드](기능모음집.md#a07) · 3D · 검색: 사각뿔 육면체 변형 morph

**하는 일:** 위쪽 네 정점을 한 꼭짓점에서 사각형으로 벌립니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `glm::mix(start, end, u)` | `1 · start` | 시작 값. 위치·색 같은 벡터 또는 크기 같은 숫자입니다. |
|  | `2 · end` | 끝 값. start와 호환되는 형태·단위여야 합니다. |
|  | `3 · u` | 단위 없는 보간 비율. 0=시작, 1=끝, 0.5=중간. 함수 자체가 0~1로 제한하지 않으므로 진행률 범위는 별도로 관리합니다. |
| `glm::vec3(x, y, z) / glm::vec3(s) / glm::vec3(v4)` | `1 · x / 2 · y / 3 · z` | 세 숫자를 전달하면 각 성분으로 저장합니다. 위치/방향에서는 X/Y/Z, 색으로 쓰면 R/G/B입니다. |
|  | `1 · s (숫자 하나)` | 세 성분을 모두 같은 값으로 만듭니다. glm::vec3(0)은 {0,0,0}입니다. |
|  | `1 · v4 (vec4 하나)` | vec4의 x,y,z 성분만 가져오고 w는 제외합니다. 이 변환 자체가 w로 나누지는 않습니다. |
| `Primitive(mode, vertices, model, color)` | `1 · mode` | 정점을 연결하는 방식. GL_POINTS=점, GL_LINES=두 점씩 선, GL_LINE_STRIP=연속선, GL_LINE_LOOP=닫힌 선, GL_TRIANGLES=세 점씩 삼각형, GL_TRIANGLE_FAN=첫 점 기준 부채꼴. |
|  | `2 · vertices` | {x,y,z} 정점들의 목록. 개수와 순서를 바꾸면 모양이 바뀝니다. 2D 예제의 z는 0이며 x/y는 논리 화면 좌표입니다. |
|  | `3 · model` | 정점에 적용할 위치·회전·크기 행렬 하나. glm::mat4(1)은 모델 변형 없음입니다. 카메라·투영은 base가 별도로 적용합니다. |
|  | `4 · color` | {r,g,b} 또는 Red/Blue 등의 색. 각 성분은 0~1, 예를 들어 {1,0,0}은 빨강입니다. |
| `glm::mat4(diagonal)` | `1 · diagonal` | 대각 성분 값. 1이면 대각만 1이고 나머지는 0인 단위행렬이 되어 모델 변형을 하지 않습니다. 모든 성분을 1로 채우는 의미가 아닙니다. |

**바꿀 값:** u=0이면 사각뿔, 1이면 육면체. 2=높이. A03의 progress를 u에 연결하면 애니메이션입니다.

**주의:** 정점 수와 연결 순서를 유지하면서 좌표만 보간합니다.

## A08 바닥 열기와 아래로 낙하

[복사할 코드](기능모음집.md#a08) · 3D · 검색: 방 바닥 문 경첩 열림 중력 떨어짐 실습21

**하는 일:** O로 바닥을 왼쪽 모서리 중심으로 아래로 열고 닫습니다. 5도를 넘겨 열면 상자가 아래로 떨어집니다. 떨어지기 시작한 상자는 바닥을 닫아도 계속 낙하하며 F5로 복원합니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnKey 내부 → OnUpdate 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnKey(key, action, mods)` | `1 · key` | 입력이 발생한 키 코드. GLFW_KEY_SPACE, GLFW_KEY_LEFT 등과 비교합니다. |
|  | `2 · action` | GLFW_PRESS=처음 누름, GLFW_REPEAT=누른 상태의 반복 입력, GLFW_RELEASE=놓음. 토글은 PRESS에서만 처리합니다. |
|  | `3 · mods` | Shift/Ctrl/Alt 등의 수정키 비트 집합. mods & GLFW_MOD_SHIFT가 0이 아니면 Shift가 함께 눌린 상태입니다. 기본 콜백이 세 값을 전달합니다. |
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `HatchModel(degrees)` | `1 · degrees` | 바닥의 열림 각도입니다. 예제는 0=닫힘, 90=수직으로 열린 상태입니다. {-3,0,0} 모서리가 고정되는 모델 행렬을 반환합니다. |
| `std::clamp(value, low, high)` | `1 · value` | 범위를 제한할 값. |
|  | `2 · low` | 포함되는 최솟값. |
|  | `3 · high` | 포함되는 최댓값. low보다 작으면 안 됩니다. value와 같은 단위·호환되는 자료형을 사용합니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |
| `R(degrees, axis)` | `1 · degrees` | 회전각, 단위는 도. 15=15도, -15=반대 회전. 내부에서 라디안으로 변환하므로 직접 radians를 적용하지 않습니다. |
|  | `2 · axis` | {x,y,z} 회전축 벡터 하나. {1,0,0}=X, {0,1,0}=Y, {0,0,1}=Z. {0,0,0}은 사용하지 않습니다. |
| `S(size)` | `1 · size` | {x,y,z} 축별 크기 배율 하나. Box의 기본 한 변이 1이므로 {6,0.2,0.8}은 전체 길이·두께·폭이 됩니다. Sphere에서는 축별 반지름입니다. 0이면 해당 축이 납작해집니다. |

**바꿀 값:** HatchModel의 {-3,0,0}=왼쪽 위 경첩, {3,-0.1,0}=경첩에서 바닥 중심까지의 거리, {6,0.2,8}=바닥 크기입니다. 90은 최대 열림 각도와 초당 회전 속도입니다. 9.8은 중력, 0.3은 상자 반높이입니다.

**주의:** 열림 각도 5도를 기준으로 바닥 지지를 끄는 학습용 모형입니다. 움직이는 바닥 면과의 정밀 접촉·충돌은 계산하지 않습니다. 방에 넣을 때 D12의 floor=false로 고정 바닥을 생략하고 room * HatchModel(...)을 그립니다. 아래로 떨어진 물체에 C08/C09의 바닥 제한을 적용하면 낙하가 막힙니다.
