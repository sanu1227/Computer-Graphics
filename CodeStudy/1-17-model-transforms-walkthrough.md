# 1-17 모델링 변환: 개발 순서대로 읽는 해설

이 문서는 [1-17.cpp](../1-4/1-4/1-17.cpp)를 처음 읽는 사람을 위한 설명이다. 실습 PDF 「지엘3 좌표계 변환 (실습 1617)」 3쪽의 17번을 구현했다.

핵심은 **객체의 위치, 자세, 크기를 따로 저장하는 것**이다. 같은 회전이라도 자기 중심에서 돌면 자전이고, 중앙 원점 주위를 돌면 공전이다.

## 먼저 실행해 본다

PowerShell에서 프로젝트의 `1-4/1-4` 폴더로 이동한 뒤 실행한다.

```powershell
.\run-exercise.ps1 -Number 17
```

[실행 스크립트](../1-4/1-4/run-exercise.ps1)가 17번을 빌드하고 실행한다. 실행 파일은 `1-4/1-4/x64/Debug/1-17/1-17.exe`다.

Visual Studio의 기본 실행 과제는 18번이다. IDE에서 17번을 기본으로 실행하려면 [프로젝트 파일](../1-4/1-4/1-4.vcxproj)의 `Exercise` 기본값을 `18`에서 `17`로 바꾼다. 스크립트는 이 파일의 기본값을 변경하지 않고 선택한 과제만 실행한다.

처음에는 왼쪽 원뿔과 오른쪽 육면체가 보인다. 좌표축과 두 객체에는 같은 x축 30도, y축 30도 기울기를 적용한다.

| 키 | 동작 |
| --- | --- |
| `1`, `2`, `3` | 처음 왼쪽 객체, 처음 오른쪽 객체, 두 객체를 선택한다. |
| `x` / `Shift+x` | 자기 x축에 대해 양 / 음 방향으로 계속 자전한다. |
| `y` / `Shift+y` | 자기 y축에 대해 양 / 음 방향으로 계속 자전한다. |
| `r` / `Shift+r` | 중앙 y축에 대해 양 / 음 방향으로 계속 공전한다. |
| `a` / `Shift+a` | 제자리에서 확대 / 축소한다. |
| `b` / `Shift+b` | 원점 기준으로 확대 / 축소한다. 위치도 변한다. |
| `d` / `Shift+d` | x축에서 왼쪽 / 오른쪽으로 이동한다. |
| `e` / `Shift+e` | y축에서 위 / 아래로 이동한다. |
| `t` | 두 객체가 원점을 지나 서로의 자리로 이동한다. |
| `u` | 한 객체는 위로, 다른 객체는 아래로 돌아 서로의 자리로 이동한다. |
| `v` | 서로 반대로 크기를 바꾸면서 자전과 공전을 한다. |
| `c` | 원뿔·육면체를 구·사각뿔로 바꾼다. 다시 누르면 복원한다. |
| `w` | 선 그리기와 면 채우기를 전환한다. |
| `s` | 모든 상태를 초기화한다. |
| `q`, `Esc` | 종료한다. |

대문자 명령은 Shift와 함께 누른다. `x`, `y`, `r`은 같은 방향의 키를 다시 누르면 해당 회전을 멈춘다. 선택을 바꾸어도 이미 시작한 다른 객체의 회전은 계속된다.

`t`, `u`, `v`, `c`는 선택 번호와 관계없이 두 객체 모두에 적용된다. `t`, `u`, `v`를 다시 누르면 현재 상태에서 멈춘다. 다른 변환 키를 누르면 두 객체 애니메이션을 멈추고 선택한 변환을 적용한다.

자리 교체 뒤에도 선택 번호는 객체를 따라간다. 1번은 처음 원뿔이었던 객체, 2번은 처음 육면체였던 객체다.

## 1. 객체 두 개를 같은 구조로 저장한다

```cpp
struct Object
{
    glm::vec3 position = glm::vec3(0.0f);
    glm::mat4 rotation = glm::mat4(1.0f);
    float size = 1.0f;
    int shape = 0;
    int spinX = 0;
    int spinY = 0;
    int orbit = 0;
};
```

`objects[0]`과 `objects[1]`에 각각 저장한다. `position`은 중심 위치이고 `rotation`은 현재 자세다. `size`는 원래 도형에 곱할 크기 배율이다.

`spinX`, `spinY`, `orbit`은 `0`이면 정지, `1`이면 양 방향, `-1`이면 음 방향이다.

`ResetObjects()`는 위치를 `(-0.85, 0, 0)`과 `(0.85, 0, 0)`으로 설정한다. 크기는 1, 자세는 단위 행렬, 선택은 두 객체다.

## 2. 정점은 처음에 한 번 만든다

`MakeVertices()`가 네 가지 도형의 정점을 `vertices`에 넣는다.

| 도형 번호 | 도형 | 만드는 방법 |
| --- | --- | --- |
| 0 | 육면체 | 여섯 면마다 꼭짓점 네 개를 저장한다. |
| 1 | 원뿔 | 원을 24조각으로 나눠 옆면과 바닥의 삼각형을 만든다. |
| 2 | 구 | 위도 12칸, 경도 24칸으로 나눠 삼각형을 만든다. |
| 3 | 사각뿔 | 옆면 네 개와 바닥 삼각형 두 개를 만든다. |

`shapeFirst`는 각 도형의 첫 정점 위치다. `shapeCount`는 정점 개수다. 마지막 여섯 정점은 x, y, z축의 양끝이다.

육면체를 선으로 그릴 때는 `GL_LINE_LOOP`를 사용한다. 면을 삼각형 둘로 나눌 때 생기는 불필요한 대각선을 피한다. 면을 채울 때는 `GL_TRIANGLE_FAN`을 사용한다.

원뿔과 구는 회전 모습이 보이도록 조각마다 다른 색을 준다. `segments`, `rings`를 늘리면 곡면이 더 부드러워지지만 정점도 늘어난다.

## 3. 입력을 선택한 객체에만 적용한다

`KeyCallback()`의 반복문은 객체 두 개를 검사한다.

```cpp
if (selectedObject != 3 && selectedObject != i + 1)
    continue;
```

둘 다 선택한 경우가 아니면서 현재 객체 번호도 다르면 건너뛴다. 이 한 조건으로 모든 기본 변환에 동일한 선택 규칙을 적용한다.

이동과 크기 변경은 `GLFW_REPEAT`도 처리한다. 키를 길게 누르면 계속 이동하거나 크기가 바뀐다. 시작·정지 명령은 반복 입력을 무시한다.

## 4. 자전과 공전의 곱셈 위치가 다르다

`UpdateAnimation()`에서 초당 60도씩 회전한다.

자전은 객체의 현재 회전 행렬 오른쪽에 새 회전을 붙인다.

```cpp
object.rotation = glm::rotate(object.rotation, angle * object.spinX, glm::vec3(1, 0, 0));
```

이때 `position`은 바꾸지 않는다. 따라서 자기 중심에 그대로 서서 자기 축으로 회전한다.

공전은 중앙 y축의 회전 행렬을 위치와 자세에 모두 적용한다.

```cpp
object.position = glm::vec3(orbit * glm::vec4(object.position, 1.0f));
object.rotation = orbit * object.rotation;
```

예를 들어 `(-0.85, 0, 0)`에서 y축 양 방향으로 90도 공전하면 `(0, 0, 0.85)`로 이동한다. 원점에서의 거리는 0.85로 유지된다.

## 5. 제자리 확대와 원점 기준 확대를 구분한다

`a`는 `size`만 1.1배로 만든다. `b`는 `size`와 `position`을 함께 1.1배로 만든다.

| 원래 상태 | `a`를 누른 뒤 | `b`를 누른 뒤 |
| --- | --- | --- |
| 위치 x = 0.85, 크기 = 1 | 위치 x = 0.85, 크기 = 1.1 | 위치 x = 0.935, 크기 = 1.1 |

축소는 1.1로 나눈다. 확대 후 축소하면 원래 값으로 돌아온다.

크기는 0.1~4로 제한한다. 원점 기준 확대에서는 실제 적용된 크기 비율을 위치에도 곱한다. 크기가 최대치에 도달한 후 위치만 계속 멀어지는 문제를 막는다.

## 6. 애니메이션 시작 위치를 저장한다

`StartAnimation()`은 현재 두 객체를 `animationStart`에 복사하고 경과 시간을 0으로 만든다.

프레임마다 직전 위치를 기준으로 조금씩 보정하는 대신, 저장한 시작 상태와 진행률로 현재 상태를 계산한다. 그래서 끝나는 위치가 정확하다.

```cpp
float progress = std::min(animationTime / animationDuration, 1.0f);
```

기본 이동 시간은 2초다. 1초가 지났다면 진행률은 0.5다. `animationDuration`을 바꾸면 `t`, `u`의 이동 시간이 달라진다.

## 7. t: 원점을 거쳐 자리를 바꾼다

진행률 0~0.5에서는 시작 위치에서 원점으로 간다. 0.5~1에서는 원점에서 상대방의 시작 위치로 간다.

이미 키로 이동시켜 두 객체 위치가 비대칭이어도 반드시 원점을 통과한다. 중간에 두 도형이 겹치는 것은 요구된 동작이다.

## 8. u: 위와 아래로 나누어 이동한다

`glm::mix(start, end, progress)`로 두 위치 사이를 이동한다. 여기에 y축 높이를 더한다.

```cpp
float height = 0.7f * std::sin(glm::radians(180.0f) * progress);
objects[i].position.y += i == 0 ? height : -height;
```

시작과 끝에서는 높이가 0이다. 중간에서는 한 객체에 +0.7, 다른 객체에 -0.7을 적용한다. 장면 전체가 기울어져 있으므로 화면에서는 좌표계의 y축 방향을 따라 움직인다.

끝에서는 상대방의 시작 위치를 직접 대입해 삼각함수의 작은 오차까지 없앤다.

## 9. v: 반대 크기 변화와 자전·공전을 합친다

공전은 초당 45도, 추가 자전은 초당 90도다. 크기 배율은 다음과 같다.

```text
처음 왼쪽 객체: 1 + 0.4 × sin(시간 × 2)
처음 오른쪽 객체: 1 - 0.4 × sin(시간 × 2)
```

하나가 커지는 동안 다른 하나는 작아진다. 배율은 0.6~1.4 사이에서 반복되며, 최종 크기에는 공통 0.1~4 제한을 적용한다.

`v`를 멈추면 현재 위치, 자세, 크기를 그대로 남긴다. `s`는 최초 상태로 되돌린다.

## 10. 한 좌표계에 두 객체를 그린다

`GetObjectTransform()`은 객체 하나의 행렬을 만든다.

```text
객체 변환 = T(position) * rotation * S(size)
최종 변환 = projection * scene * 객체 변환
```

정점에는 크기, 자세, 위치 순서로 적용된다. `scene`은 `GetSceneTransform()`에서 만든 공통 x·y축 30도 기울기다.

좌표축에는 `projection * scene`만 적용한다. 객체의 회전이나 이동 행렬은 전달하지 않으므로 축은 고정된다.

[정점 셰이더](../1-4/1-4/1-17-vertex.glsl)는 최종 행렬을 정점에 곱한다. [조각 셰이더](../1-4/1-4/1-17-fragment.glsl)는 지정한 색을 출력한다. 사각형 뷰포트를 사용하므로 창 비율이 바뀌어도 도형 비율은 유지된다.
