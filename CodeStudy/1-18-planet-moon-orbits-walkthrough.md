# 1-18 행성과 달의 공전

[1-18.cpp](../1-4/1-4/1-18.cpp)는 「지엘3 좌표계 변환 (실습 1819)」 PDF 2쪽을 구현한다. 중심 구 1개, 행성 3개, 달 3개와 공전 궤도 6개를 그린다.

## 실행

프로젝트의 `1-4/1-4` 폴더에서 실행한다.

```powershell
.\run-exercise.ps1 -Number 18
```

Visual Studio 기본 실행 과제도 18번이다. `1-4.vcxproj`의 `Exercise` 기본값을 `19`로 바꾸면 19번이 실행된다. 스크립트는 기본값을 변경하지 않고 지정한 번호를 빌드한다. 대문자 명령은 Shift와 함께 누른다.

| 키 | 동작 |
| --- | --- |
| `p` / `Shift+p` | 직각 투영 / 원근 투영 |
| `m` / `Shift+m` | 솔리드 / 와이어 모델 |
| `w` / `s` | 장면 전체를 위 / 아래로 이동 |
| `a` / `d` | 장면 전체를 왼쪽 / 오른쪽으로 이동 |
| `+` / `-` | 장면 전체의 z좌표 증가 / 감소 |
| `1` | 행성·달 궤도를 모두 1.25배 확대 / 원래 크기로 복원 |
| `2` | 중심 구의 크기·색 변화 시작 / 현재 상태에서 정지 |
| `3` | 달 궤도의 z축 회전 시작 / 현재 각도에서 정지 |
| `q`, `Esc` | 종료 |

이동 키는 일반적인 WASD 조작을 사용한다. `+`는 `Shift+=`와 숫자 키패드 `+`를 지원한다. 행성과 달의 공전은 처음부터 계속 진행한다.

## 1. 프로그램 흐름

`KeyCallback()`은 키 입력으로 상태를 바꾼다. `UpdateAnimation()`은 지난 시간만큼 각도를 바꾼다. `DrawScene()`은 현재 위치를 계산하고 화면에 그린다.

초기화, 셰이더 생성, VAO/VBO 설정, 반복문, 종료 순서는 기존 실습과 같다. 셰이더는 `1-18-vertex.glsl`, `1-18-fragment.glsl`을 사용한다.

## 2. 구와 원을 한 번 만든다

`MakeVertices()`는 구를 위도 18칸과 경도 36칸으로 나눠 삼각형을 만든다. 이 구 하나를 위치와 크기만 바꿔 일곱 번 사용한다.

공전 궤도는 xy 평면에 반지름 1인 원을 120개 점으로 만든다. `GL_LINE_LOOP`가 마지막 점과 첫 점을 연결한다.

## 3. 행성의 위치를 계산한다

`GetPlanetOrbitTransform()`은 원을 x축으로 90도 돌려 xz 평면에 놓는다. 이어서 z축 기준으로 0도, +45도, -45도 기울인다. 세 궤도의 반지름은 1.8, 2.5, 3.2다.

`GetPlanetPosition()`은 원 위의 `(cos(각도), sin(각도), 0)`에 궤도 변환을 적용한다. 궤도를 그릴 때와 위치를 구할 때 같은 행렬을 사용하므로 행성이 선 위에서 움직인다.

각속도는 초당 +22도, -33도, +47도다. 음수는 반대 방향의 공전이다. `deltaTime`을 곱하므로 프레임 수가 달라도 속도는 같다.

## 4. 달은 행성을 따라간다

`GetMoonOrbitTransform()`은 먼저 행성 중심으로 이동한다. 행성 궤도의 기울기는 상속하지 않고, 카메라의 회전을 역으로 적용하여 기본 달 궤도를 화면과 평행하게 만든다.

`3`을 누르면 이 궤도 전체를 행성 중심의 z축 기준으로 회전한다. 달 위치도 같은 변환으로 계산하므로 회전한 궤도를 따라 움직인다. 달의 공전과 궤도 자체의 회전은 별도 각도로 저장한다.

## 5. 중심 구와 장면 전체를 구분한다

`GetSunSize()`는 사인 함수로 반지름을 0.4~0.7 사이에서 바꾼다. `GetSunColor()`도 같은 시간으로 주황색과 노란색 사이를 오간다. `2`로 시간을 멈추면 크기와 색이 동시에 멈춘다.

`scenePosition`은 구와 모든 궤도를 함께 이동한다. `largeOrbits`는 궤도의 반지름만 바꾸므로 구 자체가 커지지는 않는다.

## 6. 투영과 은면 제거

최종 변환은 `투영 * 카메라 * 객체 변환`이다. `GetProjection()`이 직각 투영과 원근 투영을 선택한다. 창 크기가 바뀌면 화면 비율도 갱신한다.

`GL_DEPTH_TEST`가 뒤쪽 도형과 궤도를 가린다. 와이어 모델에서는 면의 깊이를 먼저 기록한 뒤 선을 그려 구의 뒷면 선도 숨긴다. 구의 입체감은 셰이더의 간단한 밝기 계산으로 표현한다.
