# 1-16 사각뿔 애니메이션: 개발 순서대로 읽는 해설

이 문서는 [1-16.cpp](../1-4/1-4/1-16.cpp)를 처음 읽는 사람을 위한 설명이다. 실습 PDF 「지엘3 좌표계 변환 (실습 1617)」 2쪽의 16번을 구현했다.

15번처럼 **키 입력으로 상태를 바꾸고, 시간에 따라 각도를 바꾸고, 그 각도로 행렬을 만들어 그린다.** 기존 육면체 애니메이션도 사용할 수 있다.

## 먼저 실행해 본다

Visual Studio의 기본 실행 과제는 18번이다. 16번은 프로젝트의 `1-4/1-4` 폴더에서 `.\run-exercise.ps1 -Number 16`으로 실행한다. 실행 파일은 `1-4/1-4/x64/Debug/1-16/1-16.exe`다.

PowerShell에서는 프로젝트의 `1-4/1-4` 폴더에서 다음 명령을 실행한다.

```powershell
.\run-exercise.ps1 -Number 16
```

[실행 스크립트](../1-4/1-4/run-exercise.ps1)는 빌드 후 선택한 과제를 실행한다. `-BuildOnly`를 붙이면 빌드만 한다. 17번 실행은 `-Number 17`을 사용한다.

| 키 | 동작 | 다시 누르면 |
| --- | --- | --- |
| `6` | 네 옆면을 아래 모서리에서 함께 연다. | 현재 위치에서 닫는 방향으로 바뀐다. |
| `7` | 앞, 오른쪽, 뒤, 왼쪽 면을 차례대로 평면까지 연다. | 반대 순서로 한 면씩 닫는다. |
| `8` | 앞면과 뒷면을 꼭짓점의 y축으로 돌려 교체한다. | 원래 자리로 복원한다. |
| `9` | 꼭짓점을 고정하고 네 옆면을 바깥으로 연다. | 닫는다. |
| `y` | 도형 전체를 y축으로 자전시킨다. | 정지하거나 재개한다. |
| `p` | 사각뿔과 육면체를 전환한다. | 다른 도형으로 바뀐다. |
| `h` | 은면 제거를 켜거나 끈다. | 설정을 전환한다. |
| `r` | 사각뿔의 초기 상태로 되돌린다. | 초기 상태를 유지한다. |
| `q`, `Esc` | 종료한다. | 프로그램이 종료된다. |

`6`~`9`를 누르면 사각뿔이 자동으로 선택된다. 다른 번호의 애니메이션을 시작할 때 면 상태를 초기화한다. 같은 번호를 다시 누르면 현재 각도를 유지한 채 방향만 바뀐다.

육면체에서는 15번의 `t`, `f`, `s`, `b`, `1`, `2`, `4`, `5` 명령을 그대로 사용할 수 있다. 자세한 내용은 [15번 해설](1-15-cube-pyramid-animation-walkthrough.md)을 참고한다.

## 1. 필요한 상태를 정한다

```cpp
int pyramidMode = 0;
bool pyramidOpen = false;
float pyramidAngle = 0.0f;
float sequentialAngle = 0.0f;
```

| 변수 | 역할 | 바꾸면 달라지는 것 |
| --- | --- | --- |
| `pyramidMode` | 실행 중인 번호를 저장한다. | 사용할 회전 중심과 회전 방법이 달라진다. |
| `pyramidOpen` | 여는 중인지 닫는 중인지 저장한다. | 각도가 증가하거나 감소한다. |
| `pyramidAngle` | 6, 8, 9번 명령의 현재 진행각이다. | 네 면 또는 선택한 두 면의 자세가 달라진다. |
| `sequentialAngle` | 7번 명령의 전체 진행각이다. | 움직이는 면의 순서가 달라진다. |
| `rotationSpeed` | 초당 변하는 각도다. 기본값은 60이다. | 숫자가 클수록 빨리 움직인다. |

실행 여부와 현재 각도는 다른 정보다. 닫기로 바꾸었다고 현재 각도를 0으로 만들면 애니메이션이 아니라 순간이동이 된다.

## 2. 면별 정점을 준비한다

`vertices`는 15번의 배열 구조를 사용한다. 사각뿔의 옆면은 각각 삼각형 하나다.

| 면 번호 | 면 | 정점 범위 | 정점 개수 |
| --- | --- | --- | --- |
| 0 | 앞 | 36~38 | 3 |
| 1 | 오른쪽 | 39~41 | 3 |
| 2 | 뒤 | 42~44 | 3 |
| 3 | 왼쪽 | 45~47 | 3 |
| 4 | 바닥 | 48~53 | 6 |

같은 꼭짓점 좌표도 면별로 따로 저장한다. 그래야 한 면만 회전시킬 수 있다. 바닥은 모든 사각뿔 명령에서 고정한다.

`faceColors`를 바꾸면 면 색이 바뀐다. [조각 셰이더](../1-4/1-4/1-16-fragment.glsl)는 C++에서 보낸 `faceColor`를 그대로 출력한다.

## 3. 키 입력과 시간 갱신을 연결한다

`KeyCallback()`에서 `6`~`9`를 누르면 `pyramidMode`를 선택하고 `pyramidOpen`을 반전한다. 키를 누르고 있을 때 발생하는 `GLFW_REPEAT`는 무시한다.

`UpdateAnimation()`은 이전 프레임 이후 지난 시간 `deltaTime`을 받는다.

```cpp
float angleStep = rotationSpeed * deltaTime;
float direction = pyramidOpen ? 1.0f : -1.0f;
```

0.5초가 지났다면 `60 × 0.5 = 30도` 움직인다. 열 때는 더하고 닫을 때는 뺀다. `std::clamp()`는 최소·최대 각도를 넘지 않게 막는다.

| 명령 | 저장하는 진행각 범위 |
| --- | --- |
| 6 | 0~180도 |
| 7 | 네 면의 합계 0~360도 |
| 8 | 0~180도 |
| 9 | 0~90도 |

9번의 최대 각도는 PDF에 지정되어 있지 않으므로 90도로 정했다. 메인 루프는 긴 프레임의 `deltaTime`을 0.1초까지 제한한다.

## 4. 회전 중심을 원점에 옮겼다가 되돌린다

`GetPyramidTransform(face)`는 한 면의 변환 행렬을 만든다.

```cpp
transform = glm::translate(transform, center);
transform = glm::rotate(transform, glm::radians(angle), axis);
transform = glm::translate(transform, -center);
```

정점에는 오른쪽부터 적용된다. 먼저 `-center`만큼 옮겨 회전 중심을 원점에 놓고, 회전한 뒤, 다시 `center`만큼 옮긴다. 수식은 `T(center) * R(angle) * T(-center)`다.

`pyramidHinges`는 아래 모서리의 중점이다. `pyramidAxes`는 그 모서리 방향이다. 예를 들어 앞면은 `(0, -0.4, 0.4)`를 지나는 x축으로 회전한다.

## 5. 6번: 아래에서 다시 만나도록 펼친다

네 면이 같은 진행각을 사용하지만 회전 중심과 회전축은 각각 다르다.

PDF의 “90도에서 평면”과 “180도에서 아래에서 만남”은 펼침 진행 상태로 해석했다. 사각뿔 옆면은 처음부터 기울어져 있으므로 진행각을 그대로 `glm::rotate()`에 넣으면 이 두 조건을 만족하지 못한다.

높이는 0.8, 밑면 반폭은 0.4다. 옆면을 바깥쪽 바닥 평면까지 돌리는 실제 회전각은 다음과 같다.

```cpp
float flatAngle = 90.0f + glm::degrees(std::atan2(0.4f, 0.8f));
angle *= flatAngle / 90.0f;
```

- 진행각 0도: 원래 사각뿔이다.
- 진행각 90도: 실제 약 116.565도 회전하여 바닥 평면에 놓인다.
- 진행각 180도: 실제 약 233.130도 회전하여 네 꼭짓점이 `(0, -1.2, 0)`에서 만난다.

아래 모서리는 움직이지 않는다. 사각뿔 크기를 바꾸면 `pyramidHinges`와 이 보정 계산의 높이·반폭도 함께 바꿔야 한다.

## 6. 7번: 한 면씩 움직인다

```cpp
angle = std::clamp(sequentialAngle - face * 90.0f, 0.0f, 90.0f);
```

`sequentialAngle`이 120도라면 앞면은 90도, 오른쪽 면은 30도, 나머지는 0도다. 따라서 앞면이 평면에 도착한 다음 오른쪽 면이 움직인다.

닫을 때 합계 각도를 줄이면 왼쪽, 뒤, 오른쪽, 앞 순서로 돌아온다. 각 면의 진행각은 앞 절과 같은 기울기 보정을 거친다.

## 7. 8번과 9번: 꼭짓점을 고정한다

8번은 앞면과 뒷면만 선택한다. 회전 중심은 꼭짓점 `(0, 0.4, 0)`, 회전축은 y축이다. 두 면을 180도 돌리면 서로의 자리에 도착한다. 오른쪽 면과 왼쪽 면은 그대로다.

9번은 네 옆면에 적용한다. 회전 중심은 같은 꼭짓점이고, 회전축은 각 아래 모서리와 평행하다. 아래 모서리가 바깥으로 벌어지도록 회전각의 부호를 반대로 한다.

8번과 9번은 꼭짓점을 고정해야 한다. 6번과 7번은 아래 모서리를 고정해야 한다. 이 차이가 핵심이다.

## 8. 전체 변환과 합쳐 그린다

```cpp
glm::mat4 transform = projection * model * GetPyramidTransform(face);
```

면을 먼저 움직이고, 전체 도형의 기울기와 자전을 적용하고, 화면 표시 범위로 옮긴다. [정점 셰이더](../1-4/1-4/1-16-vertex.glsl)는 이 행렬을 정점에 곱한다.

화면 좌표축은 15번과 같이 별도로 고정한다. 면을 열거나 도형을 자전시켜도 축의 위치는 변하지 않는다.
