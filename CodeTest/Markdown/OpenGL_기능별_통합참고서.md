## D01 점

[복사할 코드](기능모음집.md#d01) · 2D · 검색: 정점 점 크기

**하는 일:** 화면의 한 위치를 점으로 표시합니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `glPointSize(size)` | `1 · size` | 점의 픽셀 크기. 12.0f면 12픽셀 크기를 요청합니다. 0보다 커야 하며 지원 크기 범위는 환경에 따라 다릅니다. |
| `Primitive(mode, vertices, model, color)` | `1 · mode` | 정점을 연결하는 방식. GL_POINTS=점, GL_LINES=두 점씩 선, GL_LINE_STRIP=연속선, GL_LINE_LOOP=닫힌 선, GL_TRIANGLES=세 점씩 삼각형, GL_TRIANGLE_FAN=첫 점 기준 부채꼴. |
|  | `2 · vertices` | {x,y,z} 정점들의 목록. 개수와 순서를 바꾸면 모양이 바뀝니다. 2D 예제의 z는 0이며 x/y는 논리 화면 좌표입니다. |
|  | `3 · model` | 정점에 적용할 위치·회전·크기 행렬 하나. glm::mat4(1)은 모델 변형 없음입니다. 카메라·투영은 base가 별도로 적용합니다. |
|  | `4 · color` | {r,g,b} 또는 Red/Blue 등의 색. 각 성분은 0~1, 예를 들어 {1,0,0}은 빨강입니다. |
| `glm::mat4(diagonal)` | `1 · diagonal` | 대각 성분 값. 1이면 대각만 1이고 나머지는 0인 단위행렬이 되어 모델 변형을 하지 않습니다. 모든 성분을 1로 채우는 의미가 아닙니다. |

**바꿀 값:** 400,300=위치, 12=점의 픽셀 크기, Yellow=색.

**주의:** 점 크기의 지원 범위는 그래픽 환경에 따라 다릅니다.

**함께 쓰기:** [D02 선·연결선·테두리](도형_그리기.md#d02)

## D04 사각형

[복사할 코드](기능모음집.md#d04) · 2D · 검색: 직사각형 네모 크기 중심

**하는 일:** 중심 좌표와 전체 너비·높이를 받는 2D 사각형입니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `Rect(center, size, color, filled=true)` | `1 · center` | {x,y} 중심 좌표. 왼쪽 위 모서리 좌표가 아닙니다. 2D에서는 +x가 오른쪽, +y가 아래입니다. |
|  | `2 · size` | {width,height} 전체 너비·높이. {200,100}이면 중심에서 좌우 100, 위아래 50만큼 뻗습니다. |
|  | `3 · color` | {r,g,b} 색, 각 값 0~1. Yellow 같은 준비된 색 변수도 가능합니다. |
|  | `4 · filled` | true=면 채우기, false=테두리. 생략하면 true입니다. |

**바꿀 값:** 400,300=중심. 200,100=전체 너비·높이. 네 번째 인수 false를 추가하면 테두리입니다.

**주의:** 왼쪽 위 좌표가 아닌 중심 좌표입니다. 반너비를 전달하지 않습니다.

## D06 육면체·바닥

[복사할 코드](기능모음집.md#d06) · 3D · 검색: 상자 받침대 시소 판 크기

**하는 일:** 원점 중심 한 변 1인 상자를 늘리고 옮깁니다. 받침대·판·바닥을 같은 Box로 만듭니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |
| `S(size)` | `1 · size` | {x,y,z} 축별 크기 배율 하나. Box의 기본 한 변이 1이므로 {6,0.2,0.8}은 전체 길이·두께·폭이 됩니다. Sphere에서는 축별 반지름입니다. 0이면 해당 축이 납작해집니다. |

**바꿀 값:** S의 x,y,z=가로·높이·깊이. T의 y를 높이/2로 두면 아랫면이 y=0입니다. 바닥 예: T({0,-0.1f,0})*S({10,0.2f,10}).

**주의:** 한 번 호출하면 상자 하나입니다. 여러 개는 Box를 여러 번 호출합니다.

**함께 쓰기:** [T01 이동](변환_공전_관절.md#t01) · [T03 크기 변경](변환_공전_관절.md#t03) · [T04 여러 부품 함께 회전](변환_공전_관절.md#t04)

## D07 구

[복사할 코드](기능모음집.md#d07) · 3D · 검색: 공 반지름

**하는 일:** 원점 중심 반지름 1인 구를 배치합니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `Sphere(model, color)` | `1 · model` | 위치·회전·크기 행렬. 기본 구는 원점 중심 반지름 1이므로 S({2,2,2})는 반지름 2입니다. |
|  | `2 · color` | {r,g,b} 또는 Green 등의 색. 각 값 0~1입니다. |

|  | `2 · action` | GLFW_PRESS=처음 누름, GLFW_REPEAT=누른 상태의 반복 입력, GLFW_RELEASE=놓음. 토글은 PRESS에서만 처리합니다. |
|  | `3 · mods` | Shift/Ctrl/Alt 등의 수정키 비트 집합. mods & GLFW_MOD_SHIFT가 0이 아니면 Shift가 함께 눌린 상태입니다. 기본 콜백이 세 값을 전달합니다. |
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `Ground()` | `없음` | base에 정해진 바닥을 그립니다. 크기·위치를 인자로 받지 않으므로 바닥을 직접 조절하려면 D06의 Box를 사용합니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |
| `R(degrees, axis)` | `1 · degrees` | 회전각, 단위는 도. 15=15도, -15=반대 회전. 내부에서 라디안으로 변환하므로 직접 radians를 적용하지 않습니다. |
|  | `2 · axis` | {x,y,z} 회전축 벡터 하나. {1,0,0}=X, {0,1,0}=Y, {0,0,1}=Z. {0,0,0}은 사용하지 않습니다. |
| `S(size)` | `1 · size` | {x,y,z} 축별 크기 배율 하나. Box의 기본 한 변이 1이므로 {6,0.2,0.8}은 전체 길이·두께·폭이 됩니다. Sphere에서는 축별 반지름입니다. 0이면 해당 축이 납작해집니다. |
| `glm::vec3(x, y, z) / glm::vec3(s) / glm::vec3(v4)` | `1 · x / 2 · y / 3 · z` | 세 숫자를 전달하면 각 성분으로 저장합니다. 위치/방향에서는 X/Y/Z, 색으로 쓰면 R/G/B입니다. |
|  | `1 · s (숫자 하나)` | 세 성분을 모두 같은 값으로 만듭니다. glm::vec3(0)은 {0,0,0}입니다. |
|  | `1 · v4 (vec4 하나)` | vec4의 x,y,z 성분만 가져오고 w는 제외합니다. 이 변환 자체가 w로 나누지는 않습니다. |

**바꿀 값:** turnAxis={1,0,0}이면 X축, {0,1,0}이면 Y축, {0,0,1}이면 Z축입니다. turnPivot은 회전축이 지나는 장면 좌표 {x,y,z}입니다. turnRate는 도/초이며 클수록 빨라집니다. turnAngle은 현재 각도, turnSpeed는 부호가 있는 속도입니다. 원하는 기존 Box/Sphere/Primitive의 모델 행렬 맨 앞에 turn *를 붙여 대상을 고릅니다. Y축만 원점 중심으로 돌리려면 turnAxis={0,1,0}, turnPivot={0,0,0}으로 설정합니다.

**주의:** turnAxis에 {0,0,0}을 넣지 않습니다. 이 기능은 선택한 객체를 하나의 공통 축으로 회전합니다. 각 객체의 제자리 회전은 T02입니다. 다른 기울기와 합칠 때는 turn * tilt * 기존모델 순서입니다. tilt에 turn을 이미 포함했다면 다시 곱하지 않습니다. S키로 다른 애니메이션도 멈추려면 그 실행 상태도 함께 끕니다. 키 입력은 기존 OnKey에 합치고, turnAngle 갱신은 OnUpdate에 한 번만 넣습니다.

| `glm::mat4(diagonal)` | `1 · diagonal` | 대각 성분 값. 1이면 대각만 1이고 나머지는 0인 단위행렬이 되어 모델 변형을 하지 않습니다. 모든 성분을 1로 채우는 의미가 아닙니다. |

## I03 클릭 위치에 생성

[복사할 코드](기능모음집.md#i03) · 2D · 검색: 마우스 추가 개수 제한 사분면

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnMouse 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnMouse(button, action)` | `1 · button` | 이벤트가 발생한 마우스 버튼. GLFW_MOUSE_BUTTON_LEFT=왼쪽 버튼. |
|  | `2 · action` | GLFW_PRESS=누름, GLFW_RELEASE=놓음. 위치는 인자가 아니라 base가 갱신하는 mouseX/mouseY에서 읽습니다. |
| `items.push_back(value)` | `1 · value` | 배열 끝에 추가할 항목 하나. clickItems에는 중심 {x,y}, floorBoxes에는 3D 중심 {x,y,z}, fragments에는 {중심,속도}를 넣습니다. |

## I06 클릭한 3D 바닥에 육면체 생성

[복사할 코드](기능모음집.md#i06) · 3D · 검색: 마우스 클릭 위치 박스 상자 생성 바닥 3D 좌표 변환 광선 피킹 MouseToFloor

**하는 일:** 바닥 안을 왼쪽 클릭할 때마다 그 위치에 육면체 하나를 생성합니다. 화면의 클릭 방향과 수평 바닥이 만나는 3D 위치를 구해 저장합니다. 박스 아랫면은 floorY에 닿으며, F5로 모두 지웁니다. 원근·직교 투영 모두 지원합니다.

**하는 일:** 좌우 왕복과 위아래 왕복을 합쳐 지그재그로 이동합니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnUpdate 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `std::fmod(value, period)` | `1 · value` | 누적 시간 또는 거리. |
|  | `2 · period` | 반복 주기 또는 전체 경로 길이. 0이면 안 되며 예제에서는 양수입니다. value가 음수이면 결과도 음수일 수 있어 CornerPath는 음수 결과를 보정합니다. |
| `glm::vec2(x, y) / glm::vec2(s)` | `1 · x / 2 · y` | 두 숫자를 전달하면 각 성분으로 저장합니다. 위치이면 좌표, 속도이면 축별 이동량/초입니다. |
|  | `1 · s (숫자 하나)` | 두 성분을 모두 같은 값으로 만듭니다. glm::vec2(0)은 {0,0}입니다. |
| `Rect(center, size, color, filled=true)` | `1 · center` | {x,y} 중심 좌표. 왼쪽 위 모서리 좌표가 아닙니다. 2D에서는 +x가 오른쪽, +y가 아래입니다. |
|  | `2 · size` | {width,height} 전체 너비·높이. {200,100}이면 중심에서 좌우 100, 위아래 50만큼 뻗습니다. |
|  | `3 · color` | {r,g,b} 색, 각 값 0~1. Yellow 같은 준비된 색 변수도 가능합니다. |
|  | `4 · filled` | true=면 채우기, false=테두리. 생략하면 true입니다. |

**바꿀 값:** 120=가로 속도. y 식의 150=위쪽 시작, 300=상하 이동 폭.

**주의:** 경로를 추적하려면 매 프레임 위치를 배열에 넣고 D02의 GL_LINE_STRIP으로 그립니다. 배열 길이는 제한합니다.

## M04 나선 이동

[복사할 코드](기능모음집.md#m04) · 2D · 검색: 소용돌이 반지름 증가

**하는 일:** 반지름을 키우면서 중심 주위를 회전합니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnUpdate 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `std::min(a, b)` | `1 · a` | 비교할 첫 번째 값. |
|  | `2 · b` | 비교할 두 번째 값. 더 작은 값을 반환합니다. 예: min(1.0f,progress)는 진행률의 상한을 1로 제한하지만 하한은 제한하지 않습니다. |
| `std::sin(radians)` | `1 · radians` | 라디안 단위 각도. time*speed라면 time은 초, speed는 라디안/초입니다. 결과 범위는 -1~1입니다. |
| `std::cos(radians)` | `1 · radians` | 라디안 단위 각도. 나선 예제에서 radius*cos(angle)은 중심으로부터의 X축 오프셋입니다. 결과 범위는 -1~1입니다. |
| `glm::vec2(x, y) / glm::vec2(s)` | `1 · x / 2 · y` | 두 숫자를 전달하면 각 성분으로 저장합니다. 위치이면 좌표, 속도이면 축별 이동량/초입니다. |
|  | `1 · s (숫자 하나)` | 두 성분을 모두 같은 값으로 만듭니다. glm::vec2(0)은 {0,0}입니다. |
| `Circle(center, radius, color, filled=true)` | `1 · center` | {x,y} 원의 중심. 2D 논리 화면 좌표입니다. |
|  | `2 · radius` | 반지름. 60이면 지름은 120입니다. 양수로 지정합니다. |
|  | `3 · color` | {r,g,b} 색, 각 값 0~1. |
|  | `4 · filled` | true=채운 원, false=원 테두리. 생략하면 true입니다. |

**바꿀 값:** 400/300=중심, 200=최대 반지름, 20=반지름 증가/초, 3=라디안/초.

**주의:** 최대 반지름 이후에는 원운동입니다. 여기의 sin/cos는 라디안이고 R은 도 단위입니다.

## M06 꺾인 경로와 일정 간격 배치

[복사할 코드](기능모음집.md#m06) · 3D · 검색: 컨베이어 ㄱ자 경로 줄지어 이동

**하는 일:** 길이 6과 4인 두 구간의 경로에 상자를 같은 간격으로 놓습니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnUpdate 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `CornerPath(distance)` | `1 · distance` | 경로를 따라 진행한 누적 거리. 각도나 x좌표가 아닙니다. 현재 경로 길이는 10이며 양수·음수 거리 모두 경로 안으로 순환시킵니다. 위치·방향 행렬을 반환합니다. |
| `std::fmod(value, period)` | `1 · value` | 누적 시간 또는 거리. |
|  | `2 · period` | 반복 주기 또는 전체 경로 길이. 0이면 안 되며 예제에서는 양수입니다. value가 음수이면 결과도 음수일 수 있어 CornerPath는 음수 결과를 보정합니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |
| `R(degrees, axis)` | `1 · degrees` | 회전각, 단위는 도. 15=15도, -15=반대 회전. 내부에서 라디안으로 변환하므로 직접 radians를 적용하지 않습니다. |
|  | `2 · axis` | {x,y,z} 회전축 벡터 하나. {1,0,0}=X, {0,1,0}=Y, {0,0,1}=Z. {0,0,0}은 사용하지 않습니다. |
| `S(size)` | `1 · size` | {x,y,z} 축별 크기 배율 하나. Box의 기본 한 변이 1이므로 {6,0.2,0.8}은 전체 길이·두께·폭이 됩니다. Sphere에서는 축별 반지름입니다. 0이면 해당 축이 납작해집니다. |

**바꿀 값:** 1.5=속도, 5=개수, 2=경로상의 간격. 전체 길이는 10입니다.

**주의:** 끝에서는 시작으로 순간 복귀합니다. 한 물체만 필요하면 반복문 대신 CornerPath(pathDistance)를 사용합니다.

**주의:** 방향 길이가 0이면 이전 각도를 유지합니다. 3D에서 +Z를 보는 모델의 Y축 각도는 degrees(atan2(dx,dz))입니다.

**바꿀 값:** 3=초당 속도. 지면 위 이동만 원하면 forward.y=0으로 만든 뒤 다시 정규화합니다.

**주의:** 시선과 cameraUp이 평행하면 right를 계산할 수 없습니다. 두 이동 키를 동시에 누르면 이 예제에서는 대각선이 더 빠릅니다.

|  | `2 · w (v3, w 형태)` | 1=위치라 이동 행렬의 영향을 받음, 0=방향이라 이동의 영향을 받지 않음. 카메라 시선 회전에는 0을 씁니다. |
|  | `1 · x / 2 · y / 3 · z / 4 · w` | 숫자 네 개를 전달하면 각 성분을 직접 설정합니다. I06의 화면 좌표에서는 z=-1이 가까운 면, z=1이 먼 면이며 w=1로 시작합니다. |
| `Ground()` | `없음` | base에 정해진 바닥을 그립니다. 크기·위치를 인자로 받지 않으므로 바닥을 직접 조절하려면 D06의 Box를 사용합니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `glm::mat4(diagonal)` | `1 · diagonal` | 대각 성분 값. 1이면 대각만 1이고 나머지는 0인 단위행렬이 되어 모델 변형을 하지 않습니다. 모든 성분을 1로 채우는 의미가 아닙니다. |

**바꿀 값:** O=5도, Shift+O=반대. target은 공전 중심이면서 바라보는 점입니다.

**주의:** 물체의 공전과 카메라의 공전은 바꾸는 값이 다릅니다. 물체를 공전시키려면 T06을 사용합니다.

## P05 화면 분할

[복사할 코드](기능모음집.md#p05) · 3D · 검색: 뷰포트 다중 시점 정면도 평면도

**하는 일:** 같은 장면을 왼쪽 원근도와 오른쪽 평면도로 그립니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `SetView(x, y, width, height, from, at, up, usePerspective)` | `1 · x` | 뷰포트 왼쪽 아래 모서리의 X 좌표, 프레임버퍼 픽셀 단위. |
|  | `2 · y` | 뷰포트 왼쪽 아래 모서리의 Y 좌표, 프레임버퍼 픽셀 단위. +Y가 위이며 2D 마우스 논리 좌표와 방향이 다릅니다. |
|  | `3 · width` | 뷰포트 너비, 픽셀 단위. 0보다 커야 합니다. |
|  | `4 · height` | 뷰포트 높이, 픽셀 단위. 0보다 커야 하며 width/height로 종횡비를 계산합니다. |
|  | `5 · from` | 카메라 위치 {x,y,z}. 전체 화면 기본 설정에서는 eye입니다. |
|  | `6 · at` | 바라보는 점 {x,y,z}. 방향 벡터가 아닌 위치이며 from과 같으면 안 됩니다. 기본 설정에서는 target입니다. |
|  | `7 · up` | 화면 위쪽을 정할 방향 벡터. 보통 {0,1,0}, 바로 위에서 내려다볼 때는 {0,0,-1}. 0벡터 또는 시선과 평행한 벡터는 피합니다. |
|  | `8 · usePerspective` | true=원근 투영, false=직교 투영. 현재 base의 원근 시야각은 45도이며 이 인자는 시야각 숫자가 아닙니다. |
| `DrawViewportScene()` | `없음` | 같은 장면을 다시 그립니다. 호출 전에 SetView로 정한 시점이 적용되며, 다른 장면을 만들려면 함수 본문의 Box들을 바꿉니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |
| `S(size)` | `1 · size` | {x,y,z} 축별 크기 배율 하나. Box의 기본 한 변이 1이므로 {6,0.2,0.8}은 전체 길이·두께·폭이 됩니다. Sphere에서는 축별 반지름입니다. 0이면 해당 축이 납작해집니다. |

**바꿀 값:** SetView의 앞 네 값은 x,y,너비,높이(픽셀)입니다. DrawViewportScene의 내용만 원하는 장면으로 바꿉니다.

**주의:** OnUpdate는 프레임당 한 번만 호출합니다. 화면마다 glClear를 호출하지 않습니다. 위에서 볼 때 up은 시선과 평행하지 않게 {0,0,-1}을 씁니다.
