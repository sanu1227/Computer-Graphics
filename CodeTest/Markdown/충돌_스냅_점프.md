## C01 점이 사각형 안인지

[복사할 코드](기능모음집.md#c01) · 2D · 검색: 클릭 히트 판정 HitRect

**하는 일:** 현재 마우스가 사각형 안에 있으면 색을 바꿉니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `HitRect(x, y, center, size)` | `1 · x` | 검사할 점의 X 좌표. 마우스 판정에서는 mouseX입니다. |
|  | `2 · y` | 검사할 점의 Y 좌표. 마우스 판정에서는 mouseY입니다. |
|  | `3 · center` | 검사 대상 사각형의 중심 {x,y}. 검사할 점의 좌표와 구분합니다. |
|  | `4 · size` | 대상 사각형의 전체 너비·높이 {width,height}. 점이 내부 또는 경계에 있으면 true를 반환합니다. |
| `Rect(center, size, color, filled=true)` | `1 · center` | {x,y} 중심 좌표. 왼쪽 위 모서리 좌표가 아닙니다. 2D에서는 +x가 오른쪽, +y가 아래입니다. |
|  | `2 · size` | {width,height} 전체 너비·높이. {200,100}이면 중심에서 좌우 100, 위아래 50만큼 뻗습니다. |
|  | `3 · color` | {r,g,b} 색, 각 값 0~1. Yellow 같은 준비된 색 변수도 가능합니다. |
|  | `4 · filled` | true=면 채우기, false=테두리. 생략하면 true입니다. |

**바꿀 값:** 판정과 Rect에 같은 중심·전체 크기를 넣습니다.

**주의:** 그리기에서도 확인할 수 있지만 클릭 동작의 조건은 OnMouse에서 검사합니다.

## C02 사각형끼리 겹치는지

[복사할 코드](기능모음집.md#c02) · 2D · 검색: 충돌 AABB 접촉

**하는 일:** 축에 평행한 두 사각형의 겹침을 검사합니다.

**붙일 곳:** OnReset 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `glm::vec2(x, y) / glm::vec2(s)` | `1 · x / 2 · y` | 두 숫자를 전달하면 각 성분으로 저장합니다. 위치이면 좌표, 속도이면 축별 이동량/초입니다. |
|  | `1 · s (숫자 하나)` | 두 성분을 모두 같은 값으로 만듭니다. glm::vec2(0)은 {0,0}입니다. |
| `OverlapRect(a, sizeA, b, sizeB)` | `1 · a` | 첫 번째 사각형의 중심 {x,y}. |
|  | `2 · sizeA` | 첫 번째 사각형의 전체 너비·높이. |
|  | `3 · b` | 두 번째 사각형의 중심 {x,y}. |
|  | `4 · sizeB` | 두 번째 사각형의 전체 너비·높이. 두 사각형이 닿거나 겹치면 true를 반환합니다. |
| `Rect(center, size, color, filled=true)` | `1 · center` | {x,y} 중심 좌표. 왼쪽 위 모서리 좌표가 아닙니다. 2D에서는 +x가 오른쪽, +y가 아래입니다. |
|  | `2 · size` | {width,height} 전체 너비·높이. {200,100}이면 중심에서 좌우 100, 위아래 50만큼 뻗습니다. |
|  | `3 · color` | {r,g,b} 색, 각 값 0~1. Yellow 같은 준비된 색 변수도 가능합니다. |
|  | `4 · filled` | true=면 채우기, false=테두리. 생략하면 true입니다. |

**바꿀 값:** a,b=중심. 두 크기는 각각 전체 너비·높이입니다.

**주의:** 닿는 경우도 true입니다. 회전한 사각형의 정확한 판정에는 그대로 사용할 수 없습니다.

**함께 쓰기:** [C06 닿은 도형 지우기](충돌_스냅_점프.md#c06) · [M05 격자 이동과 장애물](이동_경로.md#m05)

## C03 가까우면 붙이기

[복사할 코드](기능모음집.md#c03) · 2D · 검색: 스냅 거리 자석 슬롯

**하는 일:** 마우스를 놓은 위치가 목표 중심에서 거리 45 이내면 목표점으로 맞춥니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnMouse 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnMouse(button, action)` | `1 · button` | 이벤트가 발생한 마우스 버튼. GLFW_MOUSE_BUTTON_LEFT=왼쪽 버튼. |
|  | `2 · action` | GLFW_PRESS=누름, GLFW_RELEASE=놓음. 위치는 인자가 아니라 base가 갱신하는 mouseX/mouseY에서 읽습니다. |
| `glm::length(v)` | `1 · v` | 길이를 구할 벡터. 두 점 사이 거리에는 현재 위치-목표 위치를 넣습니다. 위치 자체를 넣으면 원점에서 그 위치까지의 거리입니다. |
| `glm::vec2(x, y) / glm::vec2(s)` | `1 · x / 2 · y` | 두 숫자를 전달하면 각 성분으로 저장합니다. 위치이면 좌표, 속도이면 축별 이동량/초입니다. |
|  | `1 · s (숫자 하나)` | 두 성분을 모두 같은 값으로 만듭니다. glm::vec2(0)은 {0,0}입니다. |
| `Rect(center, size, color, filled=true)` | `1 · center` | {x,y} 중심 좌표. 왼쪽 위 모서리 좌표가 아닙니다. 2D에서는 +x가 오른쪽, +y가 아래입니다. |
|  | `2 · size` | {width,height} 전체 너비·높이. {200,100}이면 중심에서 좌우 100, 위아래 50만큼 뻗습니다. |
|  | `3 · color` | {r,g,b} 색, 각 값 0~1. Yellow 같은 준비된 색 변수도 가능합니다. |
|  | `4 · filled` | true=면 채우기, false=테두리. 생략하면 true입니다. |

**바꿀 값:** 600/300=목표, 45=허용 거리. 드래그와 합칠 때 snapCenter 대신 실제 dragCenter를 검사합니다.

**주의:** 이 예제 자체는 놓은 위치로 순간 이동합니다. 드래그 조합에서는 snapCenter={mouseX,mouseY} 줄을 빼고 실제 도형 중심을 사용합니다.

## C04 점프와 바닥 착지

[복사할 코드](기능모음집.md#c04) · 3D · 검색: 중력 수직 속도 낙하

**하는 일:** Space로 점프하고 중력으로 내려와 발밑 높이 0에 착지합니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnKey 내부 → OnUpdate 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnKey(key, action, mods)` | `1 · key` | 입력이 발생한 키 코드. GLFW_KEY_SPACE, GLFW_KEY_LEFT 등과 비교합니다. |
|  | `2 · action` | GLFW_PRESS=처음 누름, GLFW_REPEAT=누른 상태의 반복 입력, GLFW_RELEASE=놓음. 토글은 PRESS에서만 처리합니다. |
|  | `3 · mods` | Shift/Ctrl/Alt 등의 수정키 비트 집합. mods & GLFW_MOD_SHIFT가 0이 아니면 Shift가 함께 눌린 상태입니다. 기본 콜백이 세 값을 전달합니다. |
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `Ground()` | `없음` | base에 정해진 바닥을 그립니다. 크기·위치를 인자로 받지 않으므로 바닥을 직접 조절하려면 D06의 Box를 사용합니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |

**바꿀 값:** 6=초기 상승 속도, 9.8=중력, jumpY=발밑 높이. 상자 중심은 반높이 0.5만큼 더합니다.

**주의:** 공중에서 다시 점프하지 않도록 바닥 조건을 확인합니다. 로봇에는 Box의 위치 대신 모델 전체의 발밑 위치를 연결합니다.

**함께 쓰기:** [C05 장애물 윗면 착지](충돌_스냅_점프.md#c05) · [T05 관절에 부품 붙이기](변환_공전_관절.md#t05)

## C05 장애물 윗면 착지

[복사할 코드](기능모음집.md#c05) · 3D · 검색: 발밑 이전 높이 낙하 통과

**하는 일:** 위에서 내려오며 윗면을 통과한 경우에만 착지합니다.

**붙일 곳:** 전역: FEATURE_BLOCK_END 위 → OnReset 내부 → OnUpdate 내부 → OnDraw 내부.

**인자 설명:**

| 호출 형태 | 순서·인자 | 의미·단위·변경 결과 |
|---|---|---|
| `OnUpdate(dt)` | `1 · dt` | 직전 프레임 이후 흐른 시간, 초 단위. 속도×dt=이번 프레임 이동량입니다. base가 호출하므로 직접 상수로 넘겨 반복 호출하지 않습니다. |
| `LandOnTop(previousY, foot, vy, center, size, radius)` | `1 · previousY` | 이 프레임의 낙하 이동을 적용하기 전 발밑 Y 좌표. 물체 중심 높이가 아닙니다. |
|  | `2 · foot (&)` | 이동 후 발밑 위치 {x,y,z}. 착지하면 원본 foot.y가 장애물 윗면 높이로 바뀝니다. |
|  | `3 · vy (&)` | 수직 속도, 좌표 단위/초. 양수는 상승, 음수는 낙하이며 착지하면 원본 값이 0이 됩니다. |
|  | `4 · center` | 장애물 상자의 중심 {x,y,z}. 윗면 좌표가 아닙니다. |
|  | `5 · size` | 장애물 상자의 전체 크기 {가로,높이,깊이}. 윗면은 center.y + size.y/2입니다. |
|  | `6 · radius` | 발의 X/Z축 반크기. 예제의 한 변 1인 상자는 0.5입니다. 원형 거리 판정이 아닌 축별 겹침 범위이며 착지 성공 시 true를 반환합니다. |
| `glm::vec3(x, y, z) / glm::vec3(s) / glm::vec3(v4)` | `1 · x / 2 · y / 3 · z` | 세 숫자를 전달하면 각 성분으로 저장합니다. 위치/방향에서는 X/Y/Z, 색으로 쓰면 R/G/B입니다. |
|  | `1 · s (숫자 하나)` | 세 성분을 모두 같은 값으로 만듭니다. glm::vec3(0)은 {0,0,0}입니다. |
|  | `1 · v4 (vec4 하나)` | vec4의 x,y,z 성분만 가져오고 w는 제외합니다. 이 변환 자체가 w로 나누지는 않습니다. |
| `std::abs(value)` | `1 · value` | 절댓값을 구할 숫자. 음수 속도를 넣어도 크기는 양수로 나오므로 앞에 -를 붙여 방향을 지정할 수 있습니다. |
| `Box(model, color)` | `1 · model` | 위치·회전·크기를 합친 행렬 하나. T(...) * R(...) * S(...) 전체가 첫 번째 인자입니다. 기본 상자는 원점 중심, 각 변 길이 1입니다. |
|  | `2 · color` | {r,g,b} 또는 Yellow/Red 등의 색. 각 값 0~1. 면별 명암은 Box 함수에서 자동으로 다르게 적용합니다. |
| `T(p)` | `1 · p` | {x,y,z} 이동 벡터 하나. 세 숫자는 X/Y/Z축 이동량입니다. 단독 모델에 적용하면 중심 위치가 되고, 부모 행렬 뒤에서는 부모 좌표계에 대한 이동입니다. |
| `S(size)` | `1 · size` | {x,y,z} 축별 크기 배율 하나. Box의 기본 한 변이 1이므로 {6,0.2,0.8}은 전체 길이·두께·폭이 됩니다. Sphere에서는 축별 반지름입니다. 0이면 해당 축이 납작해집니다. |

**바꿀 값:** center/size=장애물 중심과 전체 크기. radius=발의 가로·깊이 반범위.

**주의:** 여러 장애물이 겹치면 이번 프레임에 통과한 윗면 중 가장 높은 곳을 고릅니다. 옆면 충돌과 수평 이동은 별도 기능입니다.

**주의:** 단순 축 정렬 상자 충돌입니다. 별도로 회전한 장애물의 정밀 메시 충돌은 아닙니다. 0.005초 간격 검사는 기본 크기·속도를 위한 것이며 매우 빠른 이동이나 작은 물체에는 간격을 줄이거나 연속 충돌 검사를 사용합니다. 충돌 때 멈추려면 속도 반전 대신 속도를 0으로 만듭니다. 점프·착지는 C04/C05의 발밑 높이와 연결하고 중력을 중복 갱신하지 않습니다.
